# АрхиПуть (ArchiPath)

Навигатор по году и жизни через архетипы и личный год.

## Описание
Приложение помогает пользователю планировать свои цели и задачи, опираясь на нумерологический цикл (личный год 1-9) и соответствующие ему архетипы Таро.

## Функционал
- Расчет персонального числа года по дате рождения.
- Определение архетипа года (Маг, Отшельник и др.) с описанием.
- Иерархия целей: Год -> Квартал -> Месяц -> Неделя -> День.
- Генерация задач по сферам: работа, деньги, семья, дух, здоровье.
- Трекинг выполнения задач.
- ИИ-ассистент на базе Google Gemini для персональных советов.

## Запуск
1. Установите зависимости: `npm install`
2. Запустите в режиме разработки: `npm run dev`
3. Соберите для продакшена: `npm run build`

## Настройка
- Маппинг личного года и архетипов находится в `src/constants.ts`.
- Логика расчетов и генерации в `src/utils.ts`.
- API ключи настраиваются через переменные окружения (GEMINI_API_KEY).
